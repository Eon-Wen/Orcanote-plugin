# orca-neo

虎鲸笔记（Orca Note）的 Neo 主题插件——思源笔记 Neo 主题与 Neo-Plus 插件风格的移植：注册 Neo 主题，并注入大量功能扩展（纯前端实现，无后端、无外部服务）。

## 功能

- **主题与配色**：Neo 主题 + 30+ 套配色（OKLCH 派生、明暗过滤、随机、跟随时间），自定义背景图，8→13 种纹理，毛玻璃
- **编辑器体验**：打字机模式、打字音、写作进度统计、平滑光标、彩色标题、彩色文档树、彩色列表（圆点 + 列表开头块文字上色）、无序列表原生层级线、列表活动参考线
- **列表转表格**：顶层无序/有序/任务列表一键切换表格视图（纯展示层转换，数据不动），支持缩放、全屏（自动收起侧栏）
- **表格转统计图**：表格数据生成柱状图/折线图/饼图（自绘 SVG 零依赖），弹窗实时预览、导出 PNG，可内嵌笔记（持久化、随表格数据自动更新）
- **页面/标签排序**：默认拼音/创建时间/修改时间正倒序/手动拖拽，页面与标签列表互相独立，手动排序切走再切回保持原顺序
- **批量操作**：页面多选批量改「包含于」/移到顶层
- **回收站**：拦截删除 → 快照恢复（含别名/层级/正文），居中弹窗管理、双排序
- **精细迁移引用**：反链面板勾选迁移（标签/页面/@引用自适应），含全库悬空标签修复
- **其他**：侧边栏莫兰迪彩色、缓存编辑器页签、自建设置面板 + 顶栏 Neo 菜单

## 安装

下载发布 zip，解压为 `orca-neo` 文件夹，放入虎鲸笔记插件目录（`orca/plugins/`），在设置中启用 Neo 主题。

## 开发

- 技术栈：TypeScript + Vite + CSS（纯前端注入，无后端）
- 构建：`pnpm install && pnpm build`（产物在 `dist/`）
