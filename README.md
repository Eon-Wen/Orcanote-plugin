## 🎨 项目初心
我非常喜欢思源笔记社区的 **Neo** 主题，欣赏它干净克制的视觉风格与舒适的笔记阅读体验。他是我觉得最好看的笔记主题之一
因此产生了把这套主题体验移植到虎鲸笔记的想法，希望让虎鲸的用户，也可以用上类似 Neo 的优质笔记主题。
这也是我第一次vibecoding，希望大家能够喜欢❤️，也可以让我体验一下被点star的感觉

本插件是基于思源笔记 Neo 主题进行的二次适配移植。
受限于两个软件的DOM结构差异，没有直接照搬完整源码，借助AI对样式进行改写、适配虎鲸笔记的界面结构。
我无法精准定位每一处借鉴的CSS片段，但整体UI风格大量参考源自 Neo主题。
